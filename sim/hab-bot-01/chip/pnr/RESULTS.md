## 判决

1. **平坦触发器直方图在综合上便宜、在布线上不可闭合**——GRT-0118 三连是
   结构性的；分 bank 是布线修复（顺带省 19% 面积），让设计过了全局布线。
2. **详细布线 DRC 无法在合理时间闭合**：两代路由器（相差 5,217 提交）对
   12.9k 使能触发器密度给出同级修复速率（−25~28%/轮 × 3~5h/轮，起点 20~35 万）。
   met1 短路家族 = 引脚逃逸与 PDN followpin 抢 met1。
3. **时序不是问题**：100 MHz 下 slack 巨大——失败的是 DRC 不是性能。
4. **最终工程答案（负结果的正面价值）**：真实直方图芯片用 SRAM 宏不是为了
   密度，是因为**列多路复用把读选择做进了宏的版图里**——可布线性才是 SRAM
   的第一功能。L1 账本的 SRAM 宏假设被 P&R 之路用最硬的方式平反。RTL 若要
   物理闭合，正解是 32×512 OpenRAM 宏 + 读改写流水（MB-1 同款宏已验证可 P&R）。

## 续章：SRAM 宏变体（2026-08-11）

上面的判决是「用 SRAM 宏」。这一章把它做出来而不是断言（`chip/rtl/lidar_fe_sram.v`）。

**映射**：1050 个计数器 **3×10 bit 打包进 32 位字** → `word = bin*5 + ch/3`，
350/512 字，**单颗** OpenRAM 512×32 装下。（显而易见的 2×16 bit 要 525 字、
超 512、得买两颗，反而比触发器还贵——**打包决策是这一步的胜负手**。）
10 bit 饱和不是妥协：单 bin 逼近 1024 只发生在几乎全部微元同沿触发，那正是
测距账判「只报近」的饱和近距区。

**等价性**：同一套 TB、同一批 4809 发金标准向量**原样通过**，iverilog 与 xsim
**同刻**（146115 ns）。换了存储架构，接口与真值没换——这就是等价测试该有的样子。
金标准里加了一道闸：向量峰值 361 < 1023，两变体的计数位宽差异不会悄悄咬人。

**面积 A/B**（同一 Yosys 流程，宏按黑盒）：

| 变体 | 标准单元 | 触发器 | 逻辑 | 宏 | 合计 |
|---|---|---|---|---|---|
| 触发器（分 bank） | 38,142 | 14,038 | 0.555 mm² | — | **0.555 mm²** |
| SRAM 宏 | 1,753 | 335 | 0.020 mm² | 0.285 mm² | **0.304 mm²** |

**省 45% 面积、少 95% 单元、少 98% 触发器。** 逐位：触发器 30.8 µm²/bit vs
宏 17.4 µm²/bit。所以主账里那句「SRAM 宏是可布线性答案不是密度答案」**只对了
一半**——在这个尺寸它两样都赢。

**P&R**：die 1100×700，宏 MY 取向贴核心左边界。第一次仍踩 **PDN-0179**——
宏放在 x=20 给核心边界留了 8 µm 行碎片，供不上电（MB-1 笔记里原样记着这条）；
推到 x=12.42 齐平即过。详细布线第 0 轮 **1,563** 个违例（触发器版同阶段
208,820，差两个数量级）。

**布线闭合**：详细布线违例 1563 → 525 → 361 → 110 → 41 → 14 → 3 → **0**，
`route_drc.rpt` **0 字节**。时序 setup **+0.05** / hold **+0.14** ns @100 MHz、
tns 0；天线 0 违例（GRT 报修后）；`Design area 318,154 µm² @ 44% 利用率`。
klayout 合流出 **`out/lidar_fe_sram.gds`（23.9 MB，1100×700 µm，51 层，
含 1 颗宏实例）**——**九轮之后，GDS 闭合**。

## 九轮总账

| | 触发器版 | SRAM 宏版 |
|---|---|---|
| 标准单元 / 触发器 | 38,142 / 14,038 | 1,753 / 335 |
| 综合面积 | 0.555 mm² | **0.304 mm²** |
| 全局布线 | 分 bank 后过 | 一次过 |
| 详细布线 DRC | **不闭合**（20~35 万起，−26~28%/轮 × 3~5 h） | **0**（8 轮迭代，~6 min） |
| 时序 @100 MHz | +1.14 / +0.13 | +0.05 / +0.14 |
| GDS | 无 | **有** |

一句话：**这颗前端是可流片的，但不是以我们第一次写的方式**。触发器直方图在
综合报告上赢，在布线器面前不存在；换成一颗 16 kbit 宏 + 一个打包决策后，
面积、单元数、可布线性、GDS 四样一起到手。
