## 2. 推翻了自己什么(What broke,r5)

1. **单位列大 100 倍,而且核它的闸是自比。** 原写 `KEV_UM_TO_MEVCM2MG = 1.0/2.33`(已更正为 10/2330);G4.3 写的是 `abs(K/0.4292 − 1) < 0.01`——拿常数与它自己的字面值比,从 r1 起一直绿、从来不可能红。是 ops-compute-01 用 PDG 最小电离(116 keV/300 µm)抓到的,不是我。同一个错 sci-rad-01 09-09 的回执里也有(「30 keV/µm ≈ 13 MeV·cm²/mg」,早于本册,是它独立犯的),ops-compute-01 r1.1 抄进过自己的 JSON、本轮已撤回——两册各错一次、方向相同,所以互相对不出来。教训不在常数,在闸:一道闸如果只引用被测对象自己,它就不是闸。
2. **上三行的回收是靠抵消绿的。** r2 交付写「五行对分层真值都在 ±7% 内」,r4 沿用。按真源拆开:>10 / >30 / >100 三行里,穿透类回收高于出射能那部分真值的 1.00 / 0.95 / 0.83;真停止类只回收低于出射能那部分的 0.20 / 0.08 / 0.00(慢的重离子到不了 C 层,做不出 A·C 符合——结构性);高于出射能、在碘化铯里核作用的重离子被停止类又数了一遍(占该行 12% / 18% / 23%),把洞填上。全部真闯入者去掉后 0.89 / 0.85 / 0.79。这是 r4 两条(E13.3、G14.1)之后第三条「对的数、错的理由」,同一个病:回收列是一个总量,总量对不说明各部分对。
3. **我想撤回自己 r4 的一句话,结果那句话是对的。** r4 DISPATCH 2c 写「回收 1.07 里可能有氦闯入者的一份」。r5 预注册里我用权重比粗估它 ≤1%,想把那句话降级。数据:6.3%,扣掉后 1.066 → 0.990——>1 行读高的 7% 几乎全是它。粗估漏了一点:相对论氦本身就在 >1 这一行里,而穿透类只认内圈。
4. **E17.2**:我写「质子闯入者的 L 全在 1 以下」。刚过出射能的质子在 300 µm 里沉积 0.39 MeV = 1.3 keV/µm,就在 1 以上——这个数我 r4 自己算过(账 14 文件头),没用上。
5. **全电荷旁带扣除(账 17 数据后路径)不闭合**,撤回。氦一种物种时闭合(0.97–1.07),混五种就不行:同一个中值箱里慢的碳和快的氧漏率不同,而标定束的配比不是场的配比。
6. **账 20 预注册的监测类无功效**(见上)。另:卡上 r1 写的「标定要求落在 ±5% 这一档」对碘化铯偏松——D 增益 +2…+3% 就让扣氦后的主望远镜类剂量比移 +0.05(负向只 −0.02…−0.03,不对称;扫描点之间有 ±0.02 的 MC 颗粒度)。
7. **`dev/AGREEMENTS.md` 从未存在。** README 与 `sim/field.py` 从 r1 起写「登进 AGREEMENTS」,没有这个文件。本轮补成文件(7 行),并把这件事登记在文件头。
8. **E18.1 / E19.1 两条量级预期偏出**(氦份额 0.71 对 0.30–0.55;份额变化 −0.075 / +0.110 对 ≤0.05 / ≤0.04):两次都低估了「这个口径下离子有多重」。
9. **被满足的预期,审过的:** E18.6 量得出的部分偏 +0.046(带 0.05)是擦边;它来自低能段部分读高 10%(该部分 Q≈1.7),不是主望远镜或穿透类。E16 三条命中是改完之后的核对,不算检验。

## 4. 不能闭合 / 点名留着的

- **低于出射能的高 LET 粒子**(停在 C 层之前的慢重离子):本站几何(要 A·C 符合)结构上看不见,占 >10 / >30 / >100 行真值的 13% / 11% / 5%。要那一段得是单片厚硅道;本站不给,也不把产品上限往 0.43 MeV·cm²/mg 以上延。
- **Z≥3 闯入者的扣除**:需要逐物种(或按 zproxy 连续)的转移表,本轮的混合表不闭合;没做。
- **穿透类 >100 行只回收 0.83**:原因未分解(重离子响应、L 估计量、或真值里核作用沉积),点名。
- **核作用次级的反符合否决**(r4 留下的):仍无测量,仍不造参数。r5 的重离子闯入率同样是「无否决」的保守端。
- **闪烁体猝灭与光收集不均匀**:D/E 响应仍是线性加常数分辨率;账 14 的 (D,E) 判据、账 20 的碘化铯能标、ΔE–E 拟合都压在它上面。r6。
