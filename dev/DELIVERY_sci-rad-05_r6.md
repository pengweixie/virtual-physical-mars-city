## 2. 推翻了自己什么(What broke,r6)

1. **「氦线下移,但 ³He/⁴He 的 33% 台阶不动」——错。** 预注册的物理判断前半句(同一速度下 p/d/t 的 S(E) 相同、能量按质量成比例,氢同位素判别不受 Birks 型猝灭影响)命中,变化 ≤0.02;后半句错:中心带下 ⁴He 35% 被读成 ³He,上角 71%。我的解释(6% 的光输出亏损加内圈 7% 的角度余地,够跨半个台阶)**没有单独验证**,写明是解释。
2. **我对 r5 失败原因的诊断是错的**(见上 G22.2)。它已经写进了一个提交过的文件头和一份预注册;文件头原地补了一句更正,预注册不改、在此登记。二维方法本身是对的、也闭合,但它不是修好问题的那个改动——消融才说得清是哪个改动起了作用,而我是被一道没红的必须红支逼着去做消融的。
3. **账 23 连错三个机理假设。** (a) 预注册:参考片内核作用把 Ne–Si 的 L 抬过 100,占 >100 行真值 8–25%——实际 0.6%,而且全是 Z≥10 自己。(b) 首跑后:账 08 的穿透响应从 1.2 倍出射能起标、真值从 1.0 倍起——场里的铁受大气截断从 1.67 倍出射能起,那一段是空的。(c) 再后:效率随能量变(2–30 倍段 0.121、1.2–2 倍段 0.144、对数平坦平均 0.1315)——是真的,但只值 0.94。(d) 逐物种看才发现样本量:钙 226、铁 211 个事件,±7%;硅同一张表读 1.08。高统计重跑钙 0.93、铁 0.99。**r5 交付 §4 写的「穿透类 >100 行只回收 0.83,原因未分解」应读作:约 −3% 到 −7% 是响应的能量依赖,其余是那一批 60 万事件的抽样噪声。**
4. **这也回头砸了 r5 和本轮的表。** >30 与 >100 两行的每一个回收数(r5 的 0.85 / 0.79,本轮的 0.86 / 0.82 与 0.88 / 0.82)都带 ±5–7% 的 MC 误差,而 r5 交付没有写。闸 G17.3(±8%)在这两行上的功效因此很弱。
5. **账 21 的「不知情」不是一个可用的角,是一条要求。** 我预注册时把它当作「悲观端」,以为三个结论只会小动;实际它让 χ² 切割值涨到 3–5 倍(重离子在线性模型下不再拟合得上)、闯入者涌入。结论改写为:光输出律必须在 ΔE–E 模型里,并且要用氦束与重离子束标定——质子标能不够。
6. **知情路径留下一处没修的**:两种闪烁体都猝灭时,停在 E 层的氦闯入者落进响应表近出射能的边缘箱(响应小、权重大),主望远镜类扣氦后的剂量比 1.06 → 1.16(真源分解在 `out/diag_21.txt`:氦份额按强度 0.145 → 0.43,事件数几乎不变,是权重)。该给响应表加基准体积切割(响应低于平台某一比例的箱不计);这会牵动账 10/13/15 的类定义,本轮没做。
7. **被满足的预期,审过的:** E22.1 四行命中与 E22.2 三行命中里,>30、>100 两行落在带内有运气成分(见第 4 条的 MC 误差);E21.4 两条命中(不均匀 −5%)没有发现问题。
